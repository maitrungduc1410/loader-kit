# Spec playground {#spec-playground}

在左侧编辑 JSON：每次有效的修改都会实时反映在预览中，问题会连同行号一起列出。你可以从内置 indicator 或示例开始，然后复制、下载或分享自己的 spec。自定义 spec 目前仍是实验性功能，参见[第一个 indicator](/zh/spec/)和 [JSON Schema](/zh/tools/json-schema) 页面。
