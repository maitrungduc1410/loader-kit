# Playground cho spec {#spec-playground}

Sửa JSON ở bên trái: phần xem trước cập nhật theo mỗi thay đổi hợp lệ, còn lỗi được liệt kê kèm số dòng. Bạn có thể bắt đầu từ một indicator có sẵn hoặc một ví dụ, rồi sao chép, tải về hay chia sẻ spec của mình. Spec tùy chỉnh vẫn đang ở giai đoạn experimental, xem thêm [Indicator đầu tiên](/vi/spec/) và trang [JSON Schema](/vi/tools/json-schema).
