::: info Tài liệu tham chiếu chuẩn
Trang này là bản đặc tả đầy đủ mà mọi engine của LoaderKit tuân theo. Nếu muốn làm quen từng bước, hãy bắt đầu từ [Indicator tùy chỉnh](/vi/spec/). Các đường dẫn file như `spec/src/evaluate.ts` là trong [repo GitHub](https://github.com/maitrungduc1410/loader-kit).

Phần đặc tả bên dưới được giữ nguyên bằng tiếng Anh để luôn khớp chính xác với bản gốc mà các engine tuân theo.
:::
